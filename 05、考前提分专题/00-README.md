## 时间背景

- 2026 年下半年考试已于 **2026-10-24** 结束（机考）；
- 下一场是 **2027 年上半年**，按往年规律在 5 月，报名在 3–4 月；
- 软考现在一年两考（上半年 5 月、下半年 10 月），备考窗口比过去更密。

## 一条主线

从 2024 到 2026，论文题的迁移非常明显：

**分布式事务（2024）→ 云原生数据库 + 云智一体（2025）→ 移动端 AI 测试 / 向量数据库 / 六边形架构（2026 上）→ 数据湖 / 大模型幻觉治理 / AI 运维（2026 下）**

结论：**"AI + 数据 + 云原生"已经是主线，"架构风格/质量属性/集成/可靠性"仍是保底分。** 复习时前者决定上限，后者决定下限。

## 建议的使用顺序

1. 先读 01，把"押题清单"抄成一页纸贴在桌前；
2. 再读 02，把 DFD 的四要素/五类错误、SysML 的七种关系背到能默写；
3. 最后用 03 闭卷模考，对照答案找丢分点；
4. 回到 `03、历年真题` 的 [真题考点摘要与分析](<../03、历年真题(2009年-2024年)+答案解析/真题考点摘要与分析.md>)，按薄弱年份补题。
