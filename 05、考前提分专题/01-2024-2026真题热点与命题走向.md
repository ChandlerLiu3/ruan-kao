# 2024–2026 真题热点与命题走向

> **时间说明**：本文整理到 2026-10-27。2026 年下半年考试已在 **2026-10-24** 结束，下一场是 **2027 年上半年（预计 5 月）**。所以这份材料真正服务的是 2027 年上半年。
>
> **来源说明**：以下题目均来自公开的「考生回忆版」，不是官方真题，措辞可能有出入；每年官方只公布考试大纲，不公布真题。文末列出引用页面。

## 一、最近几场考试的论文题目

| 场次 | 论文题目（4 选 1） | 备注 |
|---|---|---|
| 2024 下半年 | **论分布式事务**（回忆版仅收录此题） | 分布式一致性开始成题 |
| 2025 上半年 | 未取得可靠回忆版 | — |
| 2025 下半年（11-08） | **论基于云原生数据库的企业信息系统架构**；另有「论云智一体的 AI 应用设计与实现」等（回忆版待核） | 云原生 + AI 同场 |
| 2026 上半年（5 月） | ①论移动端 AI 测试实践 ②论高并发系统架构设计与实现 ③论向量数据库在系统中的应用 ④论六边形架构及其应用 | 四题里三题与新架构/ AI 相关 |
| 2026 下半年（10-24） | ①论数据湖的设计与实践 ②论大模型幻觉治理技术的应用与实践 ③论 IT 系统运维应用与实践（含 AI 智能运维）④（回忆版未收录） | **两道直接考大模型** |

一句话概括：**2024 还在考"分布式事务"这种经典题，2026 已经连续两场把大模型、数据湖、向量库摆到卷面上。**

## 二、五条主线

### 1. 大模型/AI：从"加分项"变成"必答题"

- 2026 上：移动端 AI 测试、向量数据库（可结合 RAG）；
- 2026 下：大模型幻觉治理（知识问答与检索增强场景）、AI 智能运维；
- 2025 下：云智一体的 AI 应用。

考法已经不是"什么是大模型"，而是**"AI 系统怎么架构"**：
- 检索增强生成（RAG）的链路：文档切分 → 向量化 → 向量库检索 → 重排 → 提示词组装 → 生成 → 引用回溯；
- 幻觉治理：检索质量、提示词约束、事实校验、置信度阈值、人工兜底、评测集；
- 工程侧：推理服务部署（GPU 池化、批处理、量化）、评测（离线集 + 线上 A/B）、可观测性（Token 成本、时延、命中率）。

### 2. 数据架构："湖仓 + 向量 + 实时"三件套

2022 湖仓一体 → 2023 数据湖 → 2024 数据分片 → 2026 上向量数据库 → 2026 下数据湖设计与实践。

命题逻辑已经从"数据库选型"升级为"**数据架构分层**"：贴源层 → 明细层 → 汇总层 → 应用层，批流一体（Lambda / Kappa），元数据与数据治理（DCMM 八能力域），以及向量库在语义检索里的位置。

### 3. 云原生与云边协同

2020 云原生 → 2021 边云协同 → 2025 下云原生数据库 → 2025 下案例"云-端协同餐饮系统" → 2026 上案例"AIoT 云边协同"。

固定考法：**分层 + 每一层放什么 + 断网/弱网怎么办 + 数据怎么同步**。

### 4. 架构方法论回潮：六边形、DDD、CQRS

2026 上考"六边形架构"（端口-适配器），2025 下案例考 DDD 的"限界上下文"。

这类题的共同点：**用"边界清晰、依赖倒置、可替换"回答"系统怎么演进"这个老问题**。答这类题的关键不是背图，而是说清"哪些是核心领域、哪些是外部适配器、依赖方向怎么指"。

### 5. 传统压舱石没变

质量属性与架构评估（案例第 1 题几乎年年必答）、企业集成、可靠性、可维护性、安全——这五类仍是"保底分"。新题再热，也没有把这些挤掉。

## 三、综合知识在考什么（2026 两场回忆）

**2026 上半年**（据考情综述）：架构风格、质量属性、微服务、Redis 高并发、云边协同仍是主线。

**2026 下半年（10-24，网友回忆）**：
- 加密算法的权衡点、国密 SM4、对称加密（AES/TripleDES/SM4）；
- 概率计算（甲乙丙各自成功率合并）、可靠性计算（MTBF 串联/并联）；
- 数据库自定义完整性约束、范式"不是为了什么"、投影后元组数量关系；
- **知识图谱的实体链接与消歧**；
- **大模型做语法分析、监督/无监督学习区别**；
- 设计模式（策略、观察者）、敏捷开发、软件著作权归属。

结论：
1. **架构与设计仍占 1/3**（约 25 题），这部分没变；
2. **AI 与数据类题已经稳定占 10–15 分**，且考得越来越"工程化"（不只是名词）；
3. 计算题（可靠性、概率、位示图、索引节点、流水线）依旧是送分/送命题，**必须动手算**。

## 四、案例分析的走向

**2025 下半年（11-08）**：
1. 电动车充电系统——质量属性场景六要素、AES-256 定长块加密超长数据怎么处理；
2. 餐饮"云-端协同"系统——DDD 限界上下文、分层架构填空、弱网点单问题；
3. Redis 缓存穿透——互斥锁方案 vs 逻辑过期方案，按"高可用"取舍；
4. 嵌入式智能 OS——智能化 OS 定义与功能、AI for OS 与 OS for AI 的场景判别。

**2026 上半年（5 月）**：
1. 网络攻击检测系统——质量属性场景 + 管道-过滤器与批处理风格选择；
2. 智慧养老家居——IoT 技术栈选配、MQTT 三种 QoS、时序数据库选型；
3. Redis 高并发与超卖——悲观锁分类与实现、悲观锁 vs 乐观锁、Redis 优化；
4. AIoT 智能安防云边协同——四层架构组件填空 + 架构缺点；
5. 在线学习系统——数据流图填空、推荐系统冷启动、知识图谱构建。

**看出来了吗**：
- 第 1 题永远是「质量属性场景 + 架构风格对比」；
- 必有一道 **Redis/缓存/高并发**；
- 必有一道 **建模**（DFD / UML / SysML）；
- 新增 **AI / IoT / 云边协同** 场景；
- 嵌入式方向从"实时调度"转向"**智能化 OS**"。

## 五、2027 备考押题清单

### 论文（按命中概率排序）

1. 大模型应用架构（RAG / Agent / 知识库）
2. AI 系统评测与治理（幻觉、安全、合规）
3. 向量数据库与语义检索
4. 数据湖 / 湖仓一体 / 实时数仓
5. 云原生与 Serverless
6. 云边协同 / 端边云一体
7. 高并发系统设计（缓存、异步、限流降级、分库分表）
8. 六边形架构 / DDD / 事件驱动
9. 可观测性（日志、指标、链路追踪）
10. 传统保底：质量属性与架构评估、企业集成、安全架构、可靠性

### 案例（六个母题）

1. 质量属性分类 + 效用树 + 风格对比（必答）
2. 缓存三件套：穿透/击穿/雪崩 + 双写一致性 + 超卖
3. 建模：DFD 填空与平衡、UML 用例/类/顺序、SysML 需求图
4. 云边协同：分层、MQTT/QoS、弱网与数据同步
5. AI 推理服务：RAG 链路、向量检索、幻觉治理
6. 数据架构：分片、主从、湖仓分层、冷热分离

## 六、怎么用这些信息

- **论文**：先按上面 1–4 备两个项目素材（一个"AI + 数据"、一个"高并发/云原生"），其余题用素材迁移。
- **案例**：把"质量属性 + 风格对比"练到 20 分钟能写完一题；Redis 三类问题各背一套标准答法。
- **综合**：架构 1/3 必须拿稳；AI 与数据的新名词按"是什么 / 解决什么问题 / 有什么代价"三句话记。
